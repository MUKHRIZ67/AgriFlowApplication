# AgriFlow Application with Gemini AI Chatbot Backend

AgriFlow is a smart agricultural management application with real-time IoT sensor telemetry, irrigation controls, automated scheduling, and an AI Farm Assistant powered by Google Gemini Developer API.

---

## 🚀 Quick Setup Instructions

### 1. Create a Free API Key from Google AI Studio
1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Log in and click **Get API key** -> **Create API Key**.
3. Copy your API Key.

> **ℹ️ Gemini Free Tier Limits:**
> Google AI Studio offers a Free Tier for `gemini-1.5-flash` with 15 Requests Per Minute (RPM) and 1,500 Requests Per Day (RPD). Using Gemini is completely free within these allowed quota limits.

---

### 2. Configure Environment Variables
1. Copy `.env.example` to `.env` in either the project root or the `server/` directory:
   ```bash
   cp .env.example .env
   ```
2. Edit `.env` and set your key:
   ```env
   GEMINI_API_KEY=your_google_ai_studio_api_key_here
   PORT=3000
   ```

> 🔒 **Security Notice:** Never commit `.env` or hard-code `GEMINI_API_KEY` in frontend code, Git commits, or public repositories.

---

### 3. Start the Application

#### Step A: Run the Backend Server
```bash
cd server
npm install
npm start
```
The backend server will run on `http://localhost:3000` with endpoint `POST /api/chat`.

#### Step B: Run the Android Application
* Open `AgriFlowApplication` in Android Studio.
* Run the app in the Android Emulator.
* The app automatically connects to the backend server at `http://10.0.2.2:3000/api/chat` (Android Emulator loopback to host `localhost:3000`).

---

## 🛠️ Chatbot Backend API Specification

* **Endpoint:** `POST /api/chat`
* **Request JSON:**
  ```json
  {
    "message": "Check soil moisture",
    "context": "Farm telemetry context string"
  }
  ```
* **Response JSON:**
  ```json
  {
    "reply": "AI response generated by Gemini model"
  }
  ```
* **Error Handling:**
  - `400`: Missing `message` or `prompt`
  - `429`: Rate limit exceeded on Gemini API
  - `500`: Missing `GEMINI_API_KEY` or Gemini API network failure
